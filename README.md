# How to Set Up Revoshop Database Locally, (In General).
## 

1. Install pg4admin dan postgresql.
2. Create a password for pg4admin access.
3. Create a database with a name of your choosing.
4. Create a table in the Schema section, then select the table.
5. You can create a table in two ways: by setting it up directly or by using a query.
6. You can edit the contents of the table according to your needs.
